02 / 音声

MN1271が生成した3チャンネル44.1 kHz PCMをモノラルへmixし、Web Audioへ出力します。ブラウザや端末の出力sample rateが異なる場合はWeb Audio側で変換されます。

ページ表示だけでは音声デバイスを開始しません。「音声を有効化」を押した後だけ、既定20%の音量で出力します。停止・ミュート・CPU一時停止・タブ非表示時は予約済み音声とPCM queueを破棄し、残音や巨大な追いつきを防ぎます。

04 / カセット

CJRをMN1271の通常信号経路で再生し、SAVE/MSAVEの出力波形をCJRへ復号します。メモリへの直接注入は行いません。

標準のBASIC（LOAD/SAVE）とマシン語（MLOAD/MSAVE）だけに対応します。PRINT#、INPUT#、ヘッダーなし、未知の種別、特殊・連結形式は黙って受け付けずエラーにします。

WASMの準備を待っています。

05 / CJRを検査

ヘッダー、ブロック境界、加算チェックサムを検査します。元ファイルは変更しません。検証済みの標準CJRはカセットWAVへ変換できます。

ファイルを選択してください。

CJRからWAVを作成

12-bit frame、固定600 baud header、leader/ブロック間隔を保ち、データ部を600または2400 baudで出力します。音量は50%、自動再生はしません。

検証済みCJRを選択してください。生成WAVの実機互換はP12で確認します。

06 / BINから標準CJRを作成

既存バイナリを1つの連続領域として格納します。BASICのトークナイズは行いません。
