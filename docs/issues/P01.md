- `make test`: macOSでCTest 3/3成功。
- `make sanitize`: AppleClang 21.0.0のASan/UBSan構成でCTest 3/3成功。
- GitHub Actions `source-and-codec` run 35619769839: commit `62263249b100330b29e9baccff1b58310747275a`に対し、Linux native、macOS native、sanitizer、Clang直接WASM smokeの4ジョブが成功。
- `EM_CACHE=$PWD/build/emcache make wasm`: Emscripten 6.0.9で正式WASM/ES moduleを生成し、`build/site`へ配置。
- 生成した`build/emscripten/web/jr200_codec.mjs`をNode.jsからinstantiateし、C ABI version 1と容量1 MiBを確認。

現在のmacOS既定AppleClangには`wasm32`ターゲットがないため、同環境での`make wasm-smoke`再実行は失敗した。直接WASM smokeの合格根拠は同じcommitに対するLinux CIの実測であり、Emscripten成功とは混同しない。EmscriptenによるCJRモジュール起動はBASIC/ROM/Canvas/入力のブラウザ起動を意味せず、それらはP06で受け入れる。
