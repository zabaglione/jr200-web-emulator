# P11 — 録音WAV解析・CJR復元

## 目的
実機やテープからのWAVを解析し、検証されたCJRを作る。

## 依存
{{P10}}

計画IDはGitHub Issue番号ではない。登録時に実際の番号へ置き換える。

## 現時点の状態
未実装。合成WAVと実機録音を別のテスト分類にする。

## 作業
- [ ] RIFF chunk/padding/長さ/PCM仕様を検査し、未対応PCMを明示拒否する
- [ ] 振幅・極性・DC・速度変動・チャンネルを診断し、フレームとブロックを復号する
- [ ] checksumエラーと時刻を報告し、無言のデータ補正を禁止する

## 受入条件
- [ ] 独立した既存ツール生成WAVを復号できる
- [ ] 無音/切断/ノイズ/逆相/不正RIFFで成功を誤報しない
- [ ] 生WAVを保存し、復元候補と検証済みCJRを区別する

## 成果物と証拠
コード、関連テスト、実行コマンド、version/commit、観測結果、未検証範囲を記録する。Issueの要件が満たされた後にのみcloseする。ローカルの一部実装はこのIssue全体の完了と同一ではない。
