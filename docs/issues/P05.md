## 受入記録（2026-09-22）

- `$C800–$C9FF`の32 byte mirror、RAM/ROM/open領域、DRAM waitを
  `JR200Machine`の明示busへ実装した。ROM/fontデータ自体は含まない。
- TCAの2 cycle fixtureでBORROW、mask、status、IRQ、normal read acknowledge、
  副作用なしdebug peekを固定した。I/O traceは元addressとdecode後registerを保持する。
- MN1544は合成2048 byte fontと末尾baud byteのKTEST/KACK全転送、100 cycle遅延、
  通常時のkey/joystick 3 byte scanを確認した。
- CMT REMOTEと論理入出力境界、整数cycle駆動の44.1 kHz 3 channel PCM queue、
  320×224 ARGB framebufferをDirectSound/Direct2Dなしで実装した。
- `make test`と`make sanitize`は各CTest 6/6成功。Emscripten同梱LLVMによる
  `make wasm-smoke`はCJR、CPU、周辺回路、JS wrapperの4試験に成功した。
  Emscripten 6.0.9の正式moduleも生成し、Node.jsから3 ABIとtimer IRQを確認した。

ここで合格したのは上流ソース対照と合成データによる周辺回路境界である。
メーカーROM/fontによるBASIC起動、Canvas/Web Audio接続、実機のregister/timing、
通常カセット波形、保存済みWAVの内容・実機互換は未検証である。
