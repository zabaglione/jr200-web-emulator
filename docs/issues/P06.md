# P06 — ブラウザBASIC起動・ROM選択・入力と画面

## 目的
利用者のローカルROM/フォントで、ブラウザ上に実際のJR-200を起動する。

## 依存
{{P05}}

計画IDはGitHub Issue番号ではない。登録時に実際の番号へ置き換える。

## 現時点の状態
2026-09-22受入完了。ローカルROM/フォント選択からC++コアを起動し、Canvas、
キーボード、ポーズ、リセット、フォーカス喪失停止へ接続した。利用者提供の
実機MSAVE録音から独立参照ツールで復元した検体を使い、Chrome、Firefox、Safariで
JR BASIC 5.0の起動と入力を確認した。詳細は
[P06_BROWSER_ACCEPTANCE.md](../P06_BROWSER_ACCEPTANCE.md) に記録した。

- [x] ROM1/ROM2または結合ROM、フォントのサイズ・順序を検査する

- [x] ROM未提供時は未起動と明示し、fake bootしない

## 受入記録（2026-09-22）

- `.emscripten-version`を`6.0.9`へ固定し、version gate付き`make wasm`、生成ES
  moduleのNode smoke、直接WASM/JS wrapper試験を成功させた。
- ROM/フォントは`local-assets/recordings/msave/`のGit対象外領域だけで扱った。
  結合ROMは16384 byte、分割ROMは各8192 byte、fontは2048 byteを要求し、
  全同一byte、RESET vector、ROM順序を検査する。
- Chrome 153.0.8010.48では`LIST`と`RUN`後の`5`、Firefox 156.0では同じ
  programとフォーカス喪失停止、Safari 26.6.2では`PRINT 7`とフォーカス喪失停止を
  実画面で確認した。ROMなしはCPU停止表示のままである。
- ブラウザ保存は既定offで、利用者がチェックした場合のみIndexedDBへ保存する。
  通常経路に外部送信はなく、配信はlocalhostの静的ファイルだけである。

音声、通常カセットLOAD/SAVE、自前WAV変換、生成WAVの実機互換はP08以降に残る。
実機録音を参照ツールでROMへ復元した事実を、これらの成功には読み替えない。
