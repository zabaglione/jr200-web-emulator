## 観測結果

- 48/44.1 kHzと600/2400 baudの全4条件で、JR2Rescueが生成WAVを読み、
  合成入力CJRと全52 byte一致した。
- 短/長half-spanとheader/data/footerの位相patternは独立波形と一致した。
  JR2RescueはVJR-200固定commitよりleaderとinter-block intervalが短く、
  各block anchor間に400 ms差があるためP12の比較対象として明記した。
- native/sanitizer各8/8、直接WASM 6系統、Emscripten 6.0.9正式module、
  Chromeの44.1 kHz/16-bit/mono/2400生成に成功した。実機読込は未実施。
- 実装commit `b89a9d1717cd892ced06ea5ff8d2ffc2bfa00dfc` のActions run
