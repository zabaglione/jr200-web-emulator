# P04 — CPUコア・メモリバスの移植

## 目的
m6800系コアを移植し、周辺回路なしで実行とデバッグの基礎を検証する。

## 依存
{{P03}}

計画IDはGitHub Issue番号ではない。登録時に実際の番号へ置き換える。

## 現時点の状態

## 作業
- [ ] m6800.h/.cpp、6800ops.hxx、6800tbl.hxx等をファイル単位で監査する
- [ ] JRSystem/global参照をバス・IRQ・waitの明示インターフェイスに置換する
- [ ] 固定幅整数、endian、命令サイクル、DRAM wait、reset/IRQ/NMI/WAIを試験する

## 受入条件
- [ ] 合成ROMで命令・フラグ・スタック・割込・境界が期待値と一致する
- [ ] native/WASMのレジスタ・メモリ・サイクルトレースが一致する
- [ ] CPU自体はWin32/cereal/UI依存を持たない

## 成果物と証拠
コード、関連テスト、実行コマンド、version/commit、観測結果、未検証範囲を記録する。Issueの要件が満たされた後にのみcloseする。ローカルの一部実装はこのIssue全体の完了と同一ではない。
